

# Video Game Tracker

### About the Project

Video Game Tracker gives users a way to track video games they are interested in, both released and upcoming. The Internet Gaming Database (IGDB) API is used for all game-related data, meaning you can add nearly any game, regardless of platform, to the tracker. Electron is used to bundle everything into a local desktop app. An SQLite database is used for persistent data storage. HTML and CSS are used for the frontend while JavaScript is used to render out the SQLite database and perform all necessary database queries.
